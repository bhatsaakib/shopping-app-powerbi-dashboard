Shopping App Power BI Dashboard

Project Overview

An interactive Power BI dashboard built to analyze shopping app transactions, food types, payment methods, delivery status, and monthly transaction trends.

Objectives

* Analyze total quantity and transaction counts.
* Compare transactions by food type and membership type.
* Analyze transactions by payment method.
* Track delivery status, including delivered and cancelled orders.
* Explore monthly trends using interactive filters.

Key KPIs

* Total Quantity
* Total Transactions
* Average Quantity

Tools Used

* Microsoft Power BI
* Power Query 
* Microsoft Excel

Dashboard Features

* Interactive slicers for month, member type, payment mode, and restaurant name.
* KPI cards for key metrics.
* Charts for monthly trends, food types, payment methods, and delivery status.

Project Files

* Shopping App.pbit — Power BI template.
* Shopping App.pdf — Dashboard export.
* Excel files — Source datasets.
* PNG files — Dashboard design assets.
